# UQAC_OPTI
code source du cours d'optimisation avancée à l'UQAC.


### pour lancer le projet :
(depuis la racine)
```
cd build
cmake ..
cmake --build .
```
cela va lancer les commandes, installer openxlsx et compiler le projet dans `build/Debug/test_opti.exe` (ou `build/Release/test_opti.exe` selon la configuration choisie)
