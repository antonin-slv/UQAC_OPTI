# UQAC_OPTI
code source du cours d'optimisation avancée à l'UQAC.

Écrit et réalisé par : Antonin Sylvestre et Thomas Blanché
### pour lancer l'application Qt
Soyez sur windows. Aucun autre prérequis.
Elle est disponible dans le dossier build_folder.
Il suffit de lancer le script [Lancer_Application.bat](./build_folder/Lancer_Application.bat) pour lancer l'application.

### Pour tester nomad en mop
1. installez NOMAD
2. placez vous dans le dossier [PROJET1/NomadTest](./PROJET1/NomadTest) dans votre terminal
3. lancez la commande
```bash
"%NOMAD_HOME%\bin\nomad.exe" param.txt
```
### Pour compiler le projet
1. installez NOMAD
2. installez QT 6.1 pour windows
3. Lancez le cmake, et voilà (avec un peu de chance)
